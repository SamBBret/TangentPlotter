This project has as an objective the drawing of a function with nothing but strings, by plotting sucessive tangents of the given fuction.
This is expected to use more than 1km of string, all tied to 1800 nails running across a 1m x 0.8m wodden frame

The script that plots the tangents can be found in "Tangentplotter.py".

The branch "frametest" was designed to check the alignement of the real world frame against the simulated version. I'm pleased to anounce this test worked perfectly
